# Shared Common Schemas

This directory houses cross-product schema definitions shared across the LOTA Security Platform suite.

---

## 1. Schema Conventions

- All schemas are authored in JSON Schema Draft-07 format.
- Every schema file must specify `$schema`, `$id`, `title`, `description`, and `type`.
- Reusable primitives include timestamps, UUID/ULID formats, and actor identity structures.
