# Shared UI Foundations

This directory defines design tokens, color systems, and reusable component specifications shared across LOTA Security product frontends (e.g. Verity Web Console).

---

## 1. Design Principles

- **High Contrast & Clarity**: Security analysts require distinct, unambiguous visual indicators for severity ratings (Critical, High, Medium, Low).
- **Zero Ambiguity**: Clear demarcation between production states and scaffolding/sandbox modes.
- **Accessibility**: Compliance with WCAG 2.1 AA contrast standards.
