# Shared Foundations

This directory contains code libraries, reusable UI tokens, and common schemas shared across all products in the **LOTA Security Platform**.

---

## Directory Organization

```text
shared/
├── python/             # Shared Python packages (e.g. lota_common)
├── ui/                 # Cross-product UI component guidelines and design tokens
└── schemas/            # Platform-wide JSON schemas and event definitions
```

---

## Package Overview

- **`shared/python/lota_common`**: Foundational Python package providing secret redaction, ID generation, custom exception hierarchies, and standardized audit event models.
