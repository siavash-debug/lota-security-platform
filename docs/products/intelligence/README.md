## 2. Product Summary

LOTA Security Intelligence is a planned threat intelligence and CTI product. It is intended to normalize, enrich, correlate, share, and operationalize threat indicators, intelligence reports, adversary Tactics, Techniques, and Procedures (TTP) mappings (such as MITRE ATT&CK), and organizational sightings.

For technical details, see [`technical-overview.md`](file:///docs/products/intelligence/technical-overview.md).
