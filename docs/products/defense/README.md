## 2. Product Summary

LOTA Security Defense is a planned detection engineering and defense operations product. It is intended to manage detection rules (Sigma, YARA, Snort/Suricata), telemetry sensor coverage, endpoint and network posture, ATT&CK matrix mapping, detection validation, and alert quality metrics.

For technical details, see [`technical-overview.md`](file:///docs/products/defense/technical-overview.md).
