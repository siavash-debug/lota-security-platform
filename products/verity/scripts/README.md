# Verity Product Scripts

This directory houses development, linting, testing, and validation scripts specific to **LOTA Security Verity**.

---

## 1. Script Catalog

- `bootstrap.sh`: Verifies Verity-specific environment and directory prerequisites.
- `lint.sh`: Runs linting across Verity API and worker Python packages.
- `test.sh`: Runs unit and endpoint health tests.
- `validate-contracts.sh`: Validates Verity OpenAPI contracts and JSON schemas.
