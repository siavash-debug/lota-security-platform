# Zeek Posture Connector

Audits the configuration posture and script loading integrity of Zeek Network Security Monitoring deployments.

---

## 1. Scope of Posture Checks

- Active Zeek version and known vulnerability posture.
- Loaded script package hashes and integrity.
- Log rotation, archiving, and integrity hashing status.
- Cluster worker load balancing and capture drop percentages.
