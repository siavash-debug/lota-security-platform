# MISP Read-Only Posture Connector

Audits the administrative and operational posture of deployed Malware Information Sharing Platform (MISP) instances.

---

## 1. Scope of Posture Checks

- Public Internet exposure of administrative endpoints.
- Multi-Factor Authentication enforcement for admin roles.
- API key age, scope, and expiration posture.
- Server synchronization peer status and TLS verification.
- Audit logging status and database backup signals.
